# Behaviour experiments

Notebooks, scripts, and measured tables for the crop models and the leave-one-day-out activity budget.

| | |
| --- | --- |
| Notebooks | This folder. Start with `00_index.ipynb`. The budget comparison is `07_farm_protocol.ipynb`. |
| Scripts | `../scripts/`. Run from that folder with `--data` pointing at the annotated clips. |
| Tables | `../results/` |

2019-12-02 is not used for training or for choosing a model. The published dense-table scores use all seven days. These tables use six days and, for the budget, the 2 Hz annotation grid.
